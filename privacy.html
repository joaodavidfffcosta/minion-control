Privacy Policy

Minion Control, a single-user application. Last updated 13 September 2026.

Summary

Minion Control has exactly one user: its owner. It collects no data from anyone else, because there is nobody else. It never sells, shares, or discloses data obtained through YouTube API Services to any third party.

Use of YouTube API Services

Minion Control uses YouTube API Services. By using it, its owner agrees to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy (https://policies.google.com/privacy).

What data is accessed

All API access is limited to the owner's own YouTube channel:

  • the identity and statistics of the owner's own channel (channels.list, mine=true)
  • videos the owner uploads, and their processing and privacy status (videos.insert, videos.list, thumbnails.set)
  • audience retention, views and estimated revenue for the owner's own channel (YouTube Analytics reports.query)

No data belonging to any other channel, video, or user is requested, received, or stored. The application does not search YouTube and does not access any end user's data, because it has no end users.

OAuth scopes and authorization

  • youtube.upload — upload videos to the owner's own channel
  • youtube.readonly — confirm the authorized channel and read uploads back
  • yt-analytics.readonly — own-channel retention and views
  • yt-analytics-monetary.readonly — own-channel estimated revenue

Authorization is granted once, by the owner, through an installed-application OAuth flow. Only one Google account is ever authorized.

Where data is stored

  • The Google OAuth client secret and refresh token are stored in the macOS Keychain on a single machine. They are never written to disk in plaintext, never transmitted to any server, and never exposed to a browser.
  • Video IDs, upload and processing status, and the owner's own channel analytics figures are stored in a private database reachable only by the owner's authenticated session.
  • Scripts, captions, renders and manifests are local production output and contain no YouTube API data.

Data retention and deletion

  • Revoking access. The owner can revoke Minion Control's access at any time at https://myaccount.google.com/permissions. Revocation takes effect immediately and the application can make no further API calls.
  • Deleting stored credentials. Deleting the Minion Control entries from the macOS Keychain destroys the refresh token and client secret on that machine permanently.
  • Deleting stored API data. Stored channel analytics and video records are deleted by the owner from the application's own control plane. Deletion is immediate and permanent.
  • Retention. Authorization data is retained only while the owner continues to operate the channel. Stored YouTube API data older than 30 days is refreshed from the API or deleted, and no API data is retained after the application is decommissioned.

What is never done

  • API data is never sold, licensed, or shared with any third party.
  • API data is never used for advertising, ad targeting, or building user profiles.
  • API data is never displayed to anyone other than the owner; there is no audience.
  • No data is combined with data from other sources to identify any person.

Children

The application is operated by an adult and the channel is general-audience content that is not made for kids. No data concerning children is collected.
